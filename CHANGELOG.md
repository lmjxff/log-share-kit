# Changelog

## 0.1.0 — 2026-10-22

- Offline redaction of common credential fields, authorization, cookies, token shapes, URL user information, private keys, email, mainland China mobile numbers, and IP literals.
- Repeatable custom keys and local literal-value files.
- Java cause-chain extraction, independent suppressed branches, source line numbers, and separate exception events.
- Markdown, JSON, and sanitized-text output.
- UTF-8 and selectable input encodings, standard input, bounded reads, and output overwrite protection.
- English and Simplified Chinese documentation, synthetic example, and regression tests.
